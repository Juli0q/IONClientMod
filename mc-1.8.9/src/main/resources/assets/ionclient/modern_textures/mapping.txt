# Where each 1.8.9 block and item texture comes from in the modern client jar.
#
#   <1.8.9 path> = <modern path> [tint r,g,b]
#
# Paths are below assets/minecraft/textures/, without ".png". A texture not listed here falls back
# to the same name in the renamed folder (blocks/stone -> block/stone, items/apple -> item/apple)
# when the modern jar has it. "-" marks a texture that is deliberately left vanilla, because its
# modern counterpart has a different layout or no longer exists.
#
# A target with a {00..63} range is a set of frames stitched into one vertical strip (the clock and
# compass, which modern versions split into one file per frame). "tint" multiplies each channel,
# for textures that modern versions colour at runtime but 1.8.9 expects coloured already.
